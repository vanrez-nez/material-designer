---
title: Document metadata
description: Metadata stores editor-only details such as document title, graph layout positions, active editor view, and UI settings. Turn it off to export only the material graph data.
---

Metadata is useful when you want to reopen the document exactly as authored in this editor.

Turning it off exports a clean material preset:

- no document title
- no editor view state
- no UI settings
- no node layout positions

The material graph nodes, parameters, sockets, groups, and connections remain in the file.
